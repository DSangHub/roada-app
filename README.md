# Roada.app

Savings membership app for high-mileage professionals (truckers, contractors, plumbers, work-truck drivers).

## Features
- Digital barcode/QR membership card
- Mileage tracker (on/off + always-on)
- Food receipt barcode reader + store
- Membership tiers: Silver (2k miles/month), Gold (5k miles/month)
- $500/month food spend bonus
- Discounts at participating gas stations and fast food
- Spanish toggle
- Start in US, expand to Canada & Mexico
